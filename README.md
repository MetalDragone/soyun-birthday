# 빵빵이가 제안하는 옥지 생일 여행

2027년 3월 7일 생일 기념 여행지 제안 사이트 (모바일 청첩장 스타일).

- `index.html` — 오프닝 영상 → 여행지 탑승권 5장 → 비교표 → 결재(카톡용 복사)
- `opening.mp4`, `finale.mp4` — 오프닝·마무리 영상 (1080p / 720p, H.264)
- `captain.svg` — 기장 빵빵이 캐릭터
- `fonts/`, `fonts.css` — 페이지에 쓰인 글자만 담은 Do Hyeon · Gowun Dodum · Nanum Pen Script (OFL)

로컬에서 보기: `python3 -m http.server` 후 http://localhost:8000

항공권 가격은 2026-11-18 구글 항공편 조회 기준(직항, 한국 항공사 우선)이며 매일 바뀝니다.
